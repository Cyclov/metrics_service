# internal/agent

Агент собирает метрики и отправляет их пакетами на `/updates/` в формате JSON с gzip-сжатием.

Ключ подписи задаётся флагом `-k=<КЛЮЧ>` или переменной окружения `KEY=<КЛЮЧ>`.
Непустая переменная `KEY` имеет приоритет над флагом. Если ключ задан, агент
передаёт в заголовке `HashSHA256` HMAC-SHA256 от сжатого тела HTTP-запроса,
закодированный в hex. При пустом ключе заголовок не добавляется.
