# Параметры запуска сервера

Параметры задаются флагами командной строки или переменными окружения.
Непустые переменные окружения имеют приоритет над флагами, затем используются
значения по умолчанию.

| Флаг | Переменная окружения | По умолчанию | Описание |
| --- | --- | --- | --- |
| `-a` | `ADDRESS` | `:8080` | Адрес и порт, на которых сервер принимает HTTP-запросы. |
| `-d` | `DATABASE_DSN` | Пустая строка | Строка подключения к PostgreSQL. Без неё используется хранилище в памяти. |
| `-i` | `STORE_INTERVAL` | `300` | Интервал сохранения метрик в файл в секундах. `0` — сохранять после каждого обновления; для периодического сохранения нужно положительное значение. |
| `-f` | `FILE_STORAGE_PATH` | Пустая строка | Путь к файлу метрик. Пустое значение отключает файловое хранение. |
| `-r` | `RESTORE` | `true` | Загружать метрики из файла при старте. Для отключения: `-r=false` или `RESTORE=false`. |
| `-k` | `KEY` | Пустая строка | Ключ HMAC-SHA256 для проверки запросов и подписи ответов. |
| `-h` | — | — | Вывести справку по флагам и завершить работу. |

Параметры `-i`, `-f` и `-r` применяются к хранилищу в памяти. При заданном
`DATABASE_DSN` или `-d` метрики хранятся в PostgreSQL.

При заданном ключе сервер проверяет непустой `HashSHA256` до распаковки gzip.
Некорректная или несовпадающая подпись приводит к `400 Bad Request` без обработки
данных. Запросы без заголовка или с пустым заголовком принимаются без проверки.
Сервер подписывает ответы, включая ошибки и пустые тела, и добавляет подпись
в `HashSHA256`. Используется HMAC-SHA256 в hex от отправляемых байтов после
gzip-сжатия, если оно применяется. Без ключа проверка и подписание отключены.

Пример запуска из корня проекта с файловым хранением:

```sh
go run ./cmd/server -a=:8080 -f=metrics.json -i=300 -r=false -k=example-key
```
