# cmd/server

В данной директории будет содержаться код Сервера, который скомпилируется в бинарное приложение.

Ключ HMAC-SHA256 задаётся флагом `-k=<КЛЮЧ>` или переменной окружения
`KEY=<КЛЮЧ>`; непустая переменная окружения имеет приоритет.

При заданном ключе сервер проверяет непустой заголовок `HashSHA256` — hex-подпись
тела запроса с этим ключом. Подпись проверяется до распаковки gzip и обработки
метрик. Некорректная или несовпадающая подпись приводит к ответу
`400 Bad Request`, данные не передаются обработчику. Если заголовок отсутствует
или пуст, запрос обрабатывается без проверки подписи.

Сервер также добавляет `HashSHA256` в ответы, включая ошибки и пустые ответы.
Подписываются фактически отправляемые байты, то есть после gzip-сжатия,
если оно применяется. Без ключа проверка и подписание отключены.
