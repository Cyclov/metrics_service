# Параметры запуска агента

Параметры задаются флагами командной строки или переменными окружения.
Непустые переменные окружения имеют приоритет над флагами, затем используются
значения по умолчанию.

| Флаг | Переменная окружения | По умолчанию | Описание |
| --- | --- | --- | --- |
| `-a` | `ADDRESS` | `localhost:8080` | Адрес сервера в формате `хост:порт`, без `http://`. |
| `-p` | `POLL_INTERVAL` | `2` | Интервал сбора метрик в секундах. Должен быть больше нуля. |
| `-r` | `REPORT_INTERVAL` | `10` | Интервал отправки метрик в секундах. Должен быть больше нуля. |
| `-k` | `KEY` | Пустая строка | Ключ подписи HMAC-SHA256. Без ключа подпись не добавляется. |
| `-h` | — | — | Вывести справку по флагам и завершить работу. |

При заданном ключе агент добавляет в запрос заголовок `HashSHA256` с HMAC-SHA256
от отправляемого тела после gzip-сжатия. Подпись кодируется в hex.
Для проверки подписи на сервере нужно задать такой же ключ.

Пример запуска из корня проекта:

```sh
go run ./cmd/agent -a=localhost:8080 -p=2 -r=10 -k=example-key
```
